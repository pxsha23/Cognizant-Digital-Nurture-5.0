## Setup
```
cd react-week5-exercises
npm install
npm run dev
```
Opens at http://localhost:5173 — all 5 exercises render on one page, top to bottom.

## What's covered
1. **Hello World Component** — confirms Vite + React project setup works
2. **Props** — `UserCard` child component receiving data from a parent
3. **State (useState)** — a counter with increment/decrement/reset
4. **Controlled Form** — text + email inputs bound to state, submit handling
5. **List & Conditional Rendering** — `.map()` over a task list, a filter checkbox,
   and an empty-state message when the filtered list is empty
